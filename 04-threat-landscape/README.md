# Cybersecurity Threat Landscape

## Overview

The cybersecurity threat landscape describes the range of threats, threat actors, attack methods, vulnerabilities, and risks that may affect information systems, organizations, and individuals.

Understanding this landscape helps security professionals identify relevant threats, assess exposure, prioritize defensive measures, and investigate suspicious activity using evidence.

## Learning Objectives

By completing this module, I aim to:

- Distinguish threats, threat actors, vulnerabilities, attack vectors, and risks.
- Recognize common cybersecurity threat categories.
- Explain how threat actors exploit weaknesses.
- Understand the relationship between likelihood, impact, and risk.
- Identify preventive, detective, and corrective security controls.
- Evaluate security observations without assuming that an attack succeeded.
- Support security conclusions with relevant, corroborating evidence.

## Learning Method

For each topic, I will:

1. Define the key concepts.
2. Explain why they matter.
3. Examine a realistic scenario.
4. Identify relevant security controls.
5. Evaluate what the available evidence does and does not establish.
6. Complete review questions or an authorized practical exercise.

## Scope and Ethics

Practical activities must be performed only on systems I own or have explicit authorization to assess. This module focuses on defensive understanding, safe analysis, and responsible security practice.
