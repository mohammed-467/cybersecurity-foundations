\# Cybersecurity Foundations



This repository documents my cybersecurity learning journey, including foundational concepts, notes, and hands-on labs.



\## Goals



\- Build a strong understanding of cybersecurity fundamentals.

\- Document concepts in clear, professional language.

\- Practice safe, ethical cybersecurity skills.

\- Develop a public portfolio that shows my progress over time.



\## Topics Covered



| Folder | Topic |

|---|---|

| `01-introduction` | Introduction to cybersecurity and the security mindset |

| `02-cia-triad` | Confidentiality, integrity, and availability |

| `03-security-domains` | Network, cloud, endpoint, application, and physical security |

| `04-threat-landscape` | Malware, phishing, social engineering, insider threats, and other threats |

| `05-security-careers` | Cybersecurity roles and career paths |

| `notes` | Study notes and key definitions |

| `labs` | Hands-on practice and lab documentation |

| `images` | Diagrams and screenshots used in documentation |



\## Learning Approach



For each topic, I will document:



1\. What the concept means.

2\. Why it matters in cybersecurity.

3\. A real-world example.

4\. Key terms to remember.

5\. Lab work or practice questions where applicable.
